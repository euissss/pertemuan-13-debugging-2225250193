## Test Case
Pengujian dilakukan terhadap:
1. Input normal.
2. Input batas minimum.
3. Input batas maksimum.
4. Input tidak valid.
5. Hasil perhitungan.

## Proses Debugging
1. Menjalankan program.
2. Mengidentifikasi kesalahan.
3. Menelusuri penyebab bug.
4. Memperbaiki kode.
5. Menjalankan kembali program.
6. Memastikan hasil sesuai harapan.

## Refleksi
